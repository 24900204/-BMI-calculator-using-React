# -BMI-calculator-using-React
## Aim

To design and develop a responsive and interactive BMI Calculator using React that accepts height and weight as inputs, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

## Procedure

Create a new React project using Vite.
Set up the required React components and CSS files.
Create input fields for height (cm) and weight (kg).
Use React useState to store and manage the input values.
Convert the height from centimeters to meters.
Calculate BMI using the formula:
BMI = Weight (kg) / Height² (m²)
Categorize the calculated BMI as:
Below 18.5 – Underweight
18.5–24.9 – Normal
25.0–29.9 – Overweight
30.0 and above – Obese
Display the calculated BMI and its category on the webpage.
Add a Reset button to clear the entered values and result.
Apply CSS styling to make the calculator responsive and user-friendly.
Add the Name and Register Number in the footer.
Run the application using npm run dev and verify the output in the browser.
